Genre Ratings Over Time

This heatmap compares major movie genres across release years from 2016 through 2026. The static view uses TMDB ratings to show how rating patterns differ across genres and years.

Years: 2016–2026
Genres: 13
Metric: Weighted Average Rating
Source: TMDB

Each cell represents one genre–year combination. Color represents the vote-count-weighted average TMDB rating. Movies with multiple genres contribute to each relevant genre. The 2026 column is marked with an asterisk because it contains partial-year data.
